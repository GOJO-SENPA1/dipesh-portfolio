## About the build

The whole site is one self-contained `index.html` — **no build step, no dependencies, no external requests.** Fonts (Bricolage Grotesque + JetBrains Mono) and the credential images are embedded, so it works offline and can be hosted on any static host or opened directly in a browser.

Design: an editorial "dossier" — cool ink + bone with a single cobalt accent, a section-index rail, and (on capable devices) a custom targeting cursor, 3D hover-tilt, a decode-on-load animation, and a parallax wireframe grid. All motion respects `prefers-reduced-motion` and degrades gracefully on touch devices.

## Run it

Open `index.html` in any browser, or serve the folder:

```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```
